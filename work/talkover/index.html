The work

Hands-free, two-way voice for Claude Code on Windows. Speak into a coding session, hear the response, and interrupt playback when you need to.

What I built

The local speech pipeline, voice panel, agent integration, and interruption behavior.

  • ListenLocal speech input through Whisper.
  • AnswerSpoken agent replies through Kokoro.
  • InterruptStop playback and pick up the conversation.

Public open-source project. See the repository for platform requirements.
